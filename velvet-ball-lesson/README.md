# Бархатный шар своими руками

Пошаговый урок Soul Home: 9 минут, 1920 × 1080, 30 кадров/с, 46 сцен. Девять предоставленных изображений. Во вступлении используется изображение шага 1. Без звуковой дорожки.

- [Скачать MP4](velvet-ball-lesson.mp4)
- [Открыть HTML-предпросмотр](index.html) — скачайте файл и откройте в браузере.
- [Субтитры SRT](subtitles.srt)
- [Текст урока](lesson-text.txt)

Редактируемый проект Remotion: `npm ci`, затем `npm run dev` и композиция `VelvetBallLesson`.

Экспорт: `npx remotion render src/index.ts VelvetBallLesson out/lesson.mp4`.
