# Нейрокот — Telegram-бот @SoulHomeRuBot

Бот мастерской и школы ручной работы Soul of Home.

## Что умеет

- **/start** — приветствие с картинкой Нейрокота и меню из кнопок.
- **Разделы:** коллекция шаров, программы обучения (с карточкой каждого курса), бесплатные уроки.
- **Заявки:** человек выбирает курс или «Заказать шар», пишет комментарий — карточка приходит мастеру.
- **Вопросы:** на любое сообщение отвечает Нейрокот через ИИ Claude (если указан ключ API). Без ключа — отвечает по базе частых вопросов и пересылает вопрос мастеру.
- **Ответ мастера:** мастер делает *reply* на карточку от бота в своём чате — бот пересылает ответ клиенту.
- **Фото и файлы** от клиентов (например, готовая работа на разбор) пересылаются мастеру.
- **Ссылки с сайта:** `t.me/SoulHomeRuBot?start=velvet` сразу открывает курс. Коды: `velvet`, `embroidery`, `collection`, `home`, `holiday`, `business`, `order` (заказ шара), `kursy`, `uroki`.

Все тексты — в файле `knowledge.py`. Меняйте их там и перезапускайте бота.

## Запуск за 10 минут

1. **Токен.** В Telegram откройте @BotFather → `/mybots` → @SoulHomeRuBot → *API Token*. Скопируйте токен.
2. **Сервер.** Нужен компьютер, который работает постоянно: любой VPS с Linux и Python 3.10+.
3. **Установка:**
   ```bash
   sudo mkdir -p /opt/soulhome-bot && sudo chown $USER /opt/soulhome-bot
   # скопируйте сюда файлы из архива
   cd /opt/soulhome-bot
   python3 -m venv venv
   ./venv/bin/pip install -r requirements.txt
   cp .env.example .env
   nano .env            # вставьте BOT_TOKEN
   ./venv/bin/python bot.py
   ```
4. **Чат мастера.** Напишите боту `/myid`, впишите число в `ADMIN_CHAT_ID` в `.env` и перезапустите. Можно использовать и группу: добавьте бота в группу, напишите там `/myid`.
5. **Автозапуск:**
   ```bash
   sudo useradd -r soulhome && sudo chown -R soulhome /opt/soulhome-bot
   sudo cp soulhome-bot.service /etc/systemd/system/
   sudo systemctl enable --now soulhome-bot
   sudo journalctl -u soulhome-bot -f     # логи
   ```

## ИИ-ответы Нейрокота

Нужен ключ Anthropic API: console.anthropic.com → *API Keys*. Впишите его в `ANTHROPIC_API_KEY`.
Модель по умолчанию — `claude-haiku-4-5-20251001` (быстрая и недорогая); можно поменять в `ANTHROPIC_MODEL`.
Бот помнит последние 12 реплик каждого чата, пока работает.

Важно: Anthropic API доступен не во всех странах. Сервер с ботом должен находиться там, где сервис доступен, а оплата API — с карты, которую принимает Anthropic. Если ключа нет, бот всё равно работает: меню, заявки и ответы по базе вопросов.

## Если мастер пишет боту из своего личного чата

Когда `ADMIN_CHAT_ID` — ваш личный чат, бот считает вас мастером: ваши сообщения не идут в ИИ. Чтобы проверить бота как клиент, используйте другой аккаунт или сделайте чатом мастера отдельную группу.
