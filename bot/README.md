# Нейрокот — Telegram-бот @SoulHomeRuBot для сайта Soul of Home

Устроен так же, как боты Salon de Fleur и «Рядом»: один бот на Cloudflare Workers в двух ролях. Свой сервер не нужен, бесплатного тарифа хватает.
Это тот же Нейрокот, что раньше работал для старого сайта (`soul_of_house`), перенесённый на новый сайт.

## Что умеет

**Консультант** (`/start`, фото Нейрокота и меню):
- 🎄 **Коллекция шаров** — 12 моделей, кнопка «Заказать шар» и ссылка на страницу «Мои работы»;
- 🎓 **Обучение** — карточка каждой из 6 программ и кнопка «Записаться»;
- 📚 **Бесплатные уроки** — 8 коротких уроков об уюте и первом бархатном шаре;
- ✍️ **Оставить заявку** — курс, заказ шара или вопрос мастеру. Заявка приходит мастеру и сохраняется в Supabase, в ту же таблицу `soul_home_leads`, что и заявки с сайта (с пометкой `source = telegram`);
- 🐱 **Спросить Нейрокота** — на свободные вопросы отвечает ИИ (OpenRouter или Claude, если задан ключ). Без ключа бот отвечает по базе частых вопросов и пересылает вопрос мастеру;
- фото и файлы клиента пересылаются мастеру. Мастер отвечает **reply** на карточку, и бот передаёт ответ клиенту.

**Ссылки с сайта** открывают нужный раздел: `t.me/SoulHomeRuBot?start=velvet` (курс), `order` (заказ шара), `kursy`, `uroki`. Все кнопки «Записаться в Telegram» на сайте уже так устроены.

**Воронка для компаний «Офис к Новому году»** (`?start=office`): чек-лист, 6 сообщений по будням 10–19 МСК, кнопка «Отправить мой номер», `/stop`, «Напомнить в октябре». Статистика — команда `/funnel` в чате мастера.

**Уведомления о заявках с сайта.** Форма на странице «Обучение» сохраняет заявку в Supabase, а копию отправляет боту на `/lead`. Мастеру приходит карточка с номером заявки. Если клиент потом нажмёт «Продолжить в Telegram», бот напишет мастеру «Клиент по заявке №… открыл бота», и ему можно ответить прямо там.

## Как запустить (≈20 минут)

> ⚠️ У бота @SoulHomeRuBot один адрес для сообщений. Если он сейчас работает на сервере (Python-версия) или в другом воркере, после шага 4 сообщения начнут приходить сюда. Старую версию после этого можно выключить.

### 1. Токен
Токен @SoulHomeRuBot есть в [@BotFather](https://t.me/BotFather) → `/mybots` → SoulHomeRuBot → **API Token**.

### 2. Worker в Cloudflare
1. [dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages → Create → Create Worker**, имя `soulhome-bot`, **Deploy**.
2. **Edit code** → удалите всё, вставьте содержимое `worker.js`, **Deploy**.
3. Запишите адрес: `https://soulhome-bot.ваше-имя.workers.dev`.

### 3. Память и расписание (для воронки и ИИ)
1. **Storage & Databases → KV → Create**, имя `SOULHOME_KV`.
2. В воркере: **Settings → Bindings → Add → KV namespace**, имя переменной `KV`, выберите `SOULHOME_KV`.
3. **Settings → Triggers → Cron Triggers → Add**: `*/5 * * * *`.

Без KV бот тоже работает, но воронка не присылает сообщения по расписанию, а ИИ не помнит прошлые реплики.

### 4. Переменные
**Settings → Variables and Secrets**:

| Имя | Тип | Значение |
|---|---|---|
| `BOT_TOKEN` | Secret | токен @SoulHomeRuBot |
| `WEBHOOK_SECRET` | Secret | латиница и цифры, 20+ символов, например `SoulHome2026SecretKey99` |
| `SITE_URL` | Text | адрес сайта на Vercel, например `https://soul-of-home.vercel.app/` |
| `ALLOWED_ORIGIN` | Text | тот же адрес без пути: `https://soul-of-home.vercel.app` |
| `ADMIN_CHAT_ID` | Text | пока пусто, см. шаг 6 |
| `AI_API_KEY` | Secret | необязательно: ключ [OpenRouter](https://openrouter.ai/keys) (есть бесплатные модели) |
| `ANTHROPIC_API_KEY` | Secret | необязательно: ключ Claude, если не задан `AI_API_KEY` |

### 5. Подключить бота
Откройте `https://soulhome-bot.ваше-имя.workers.dev/setup?key=ВАШ_WEBHOOK_SECRET`. Должен появиться ответ с `"ok":true`.

### 6. Чат мастера
Напишите боту `/myid` с аккаунта мастера, вставьте число в `ADMIN_CHAT_ID`, **Deploy**. Можно сделать чатом мастера группу: добавьте туда бота и напишите `/myid` в группе.

### 7. Подключить сайт
В `site.js` найдите `var LEAD_URL = '';` и впишите адрес воркера:
```js
var LEAD_URL = 'https://soulhome-bot.ваше-имя.workers.dev/lead';
```
Сохраните в `main` — Vercel обновит сайт сам.

## Проверка
- `/status` — токен, вебхук (`webhook_points_here: true`), KV, ИИ, последняя ошибка.
- `/test-lead?key=ВАШ_WEBHOOK_SECRET` — мастеру придёт тестовая заявка.
- Тесты без интернета: `node bot/test.mjs` (42 сценария).

## Как поменять тексты
Всё в начале `worker.js`: `WELCOME`, `COLLECTION`, `COURSES`, `LESSONS`, `FAQ`, воронка — `STEPS` и `PACKAGES`. Знания для ИИ собираются из этих же текстов. На сайте те же сведения записаны в `api/_prompt.js` и `RULES` в `site.js`: меняя содержание, правьте все три места.

## Защита
- Вебхук принимается только с секретным заголовком Телеграма.
- `/lead` — только с адреса из `ALLOWED_ORIGIN`, не больше 5 заявок с одного IP за 10 минут (при подключённом KV), поле-ловушка для спам-ботов, HTML из полей вырезается.
- Ключ Supabase в боте публичный и даёт только право добавить заявку: прочитать заявки через него нельзя.
