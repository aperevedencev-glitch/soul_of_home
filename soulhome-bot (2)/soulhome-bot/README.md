# Нейрокот — Telegram-бот @SoulHomeRuBot

Бот мастерской и школы ручной работы Soul of Home.

## Что умеет

- **/start** — приветствие с картинкой Нейрокота и меню из кнопок.
- **Разделы:** коллекция шаров, программы обучения (с карточкой каждого курса), бесплатные уроки.
- **Заявки:** человек выбирает курс или «Заказать шар», пишет комментарий — карточка приходит мастеру.
- **Вопросы:** на любое сообщение отвечает Нейрокот через ИИ Claude (если указан ключ API). Без ключа — отвечает по базе частых вопросов и пересылает вопрос мастеру.
- **Ответ мастера:** мастер делает *reply* на карточку от бота в своём чате — бот пересылает ответ клиенту.
- **Фото и файлы** от клиентов (например, готовая работа на разбор) пересылаются мастеру.
- **Ссылки с сайта:** `t.me/SoulHomeRuBot?start=velvet` сразу открывает курс. Коды: `velvet`, `embroidery`, `collection`, `home`, `holiday`, `business`, `order` (заказ шара), `kursy`, `uroki`.

Все тексты — в файле `knowledge.py`. Меняйте их там и перезапускайте бота.

## Запуск за 10 минут

1. **Токен.** В Telegram откройте @BotFather → `/mybots` → @SoulHomeRuBot → *API Token*. Скопируйте токен.
2. **Сервер.** Нужен компьютер, который работает постоянно: любой VPS с Linux и Python 3.10+.
3. **Установка:**
   ```bash
   sudo mkdir -p /opt/soulhome-bot && sudo chown $USER /opt/soulhome-bot
   # скопируйте сюда файлы из архива
   cd /opt/soulhome-bot
   python3 -m venv venv
   ./venv/bin/pip install -r requirements.txt
   cp .env.example .env
   nano .env            # вставьте BOT_TOKEN
   ./venv/bin/python bot.py
   ```
4. **Чат мастера.** Напишите боту `/myid`, впишите число в `ADMIN_CHAT_ID` в `.env` и перезапустите. Можно использовать и группу: добавьте бота в группу, напишите там `/myid`.
5. **Автозапуск:**
   ```bash
   sudo useradd -r soulhome && sudo chown -R soulhome /opt/soulhome-bot
   sudo cp soulhome-bot.service /etc/systemd/system/
   sudo systemctl enable --now soulhome-bot
   sudo journalctl -u soulhome-bot -f     # логи
   ```

## ИИ-ответы Нейрокота

Бот работает с любым OpenAI-совместимым сервисом и с Claude. Выбор — в `.env`.

**Бесплатно — Qwen3.8 27B через OpenRouter (настроено по умолчанию).**
1. Зарегистрируйтесь на openrouter.ai (карта не нужна).
2. *Keys* → *Create key* → скопируйте ключ (начинается с `sk-or-`).
3. Впишите его в `.env`: `AI_API_KEY=sk-or-...`. Строки `AI_BASE_URL=https://openrouter.ai/api/v1` и `AI_MODEL=qwen/qwen3.8-27b:free` уже заполнены.
4. Перезапустите бота: `sudo systemctl restart soulhome-bot`. В логах: «ИИ: qwen/qwen3.8-27b:free через https://openrouter.ai/api/v1».

Ограничения бесплатной модели: около 20 запросов в минуту и 200 в день на аккаунт (у OpenRouter дневной лимит выше, если на балансе есть хотя бы небольшая сумма). Бесплатные модели иногда перегружены или исчезают из каталога. В этих случаях бот отвечает по базе частых вопросов и пересылает вопрос мастеру, а модель можно заменить в `AI_MODEL`.

**DeepSeek (платно, но очень дёшево) — вариант 2 в `.env.example`.**
1. Зарегистрируйтесь на platform.deepseek.com.
2. Пополните баланс в разделе *Top up* (минимальная сумма и способы оплаты указаны там).
3. *API keys* → *Create new API key* → скопируйте ключ в `AI_API_KEY`.
4. Впишите `AI_BASE_URL=https://api.deepseek.com` и `AI_MODEL=deepseek-flash` (быстрая и самая дешёвая модель; `deepseek-v4-pro` — умнее и дороже).
5. Перезапустите бота: `sudo systemctl restart soulhome-bot`. 

Бесплатного API у DeepSeek нет (бесплатен только чат на сайте), но он очень дешёвый: ответ Нейрокота стоит доли цента, тысяча ответов — порядка одного доллара. Повторяющаяся инструкция Нейрокота кэшируется DeepSeek автоматически, это ещё дешевле.

**Claude (Anthropic).** Впишите `ANTHROPIC_API_KEY`, оставив `AI_API_KEY` пустым. Сервис доступен не во всех странах.

Бот помнит последние 12 реплик каждого чата, пока работает. Если ИИ недоступен или кончился баланс, бот не ломается: отвечает по базе частых вопросов и пересылает вопрос мастеру.

## Если мастер пишет боту из своего личного чата

Когда `ADMIN_CHAT_ID` — ваш личный чат, бот считает вас мастером: ваши сообщения не идут в ИИ. Чтобы проверить бота как клиент, используйте другой аккаунт или сделайте чатом мастера отдельную группу.
